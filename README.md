## Тема проекта

**Smart Student Planner — мобильный ежедневник и учебный планнер для студентов с загрузкой расписания Пермского Политеха и отдельным устройством на Raspberry Pi(или на khadas).**

## Идея проекта

Хотим сделать приложение, в котором студент сможет хранить в одном месте:

- своё расписание;
- личные задачи и события;
- домашние задания;
- дедлайны;
- заметки;
- напоминания.

Главная особенность проекта - автоматическая загрузка расписания с сайта Пермского Политеха. Расписание публикуется в Excel-файлах, поэтому сервер будет скачивать файл, разбирать его и добавлять занятия нужной группы в планнер.

## Что будет в Android-приложении

Android-приложение разрабатывается на **Java + Android SDK**.

Основной функционал:

- регистрация и авторизация;
- создание и редактирование своих задач и событий;
- просмотр расписания;
- домашние задания по предметам;
- дедлайны;
- отметка выполнения задач;
- заметки к любой записи;
- push-уведомления о занятиях, задачах и дедлайнах.

Например, к паре по базам данных можно добавить заметку:

> На следующей паре защита лабораторной №4.

## Расписание Пермского Политеха

Пользователь выбирает свою учебную группу.

Сервер:

1. получает Excel-файл с расписанием;
2. находит нужную группу;
3. разбирает занятия;
4. сохраняет их;
5. отправляет расписание в приложение.

Если расписание изменилось, данные можно обновить и отправить пользователю уведомление.

## Домашние задания

Для каждого предмета можно создавать домашние задания.

У домашнего задания будут:

- название;
- предмет;
- описание;
- дедлайн;
- статус;
- приоритет;
- заметки.

Дедлайны также отображаются в общем календаре.

## Интеграции

Планируем сделать несколько простых интеграций:

- **VK API** — отправка уведомлений о занятиях и дедлайнах;
- **Пермский Политех** — загрузка расписания из Excel.

## Raspberry Pi

Для выполнения требований курса будет отдельная программа под Linux для **Raspberry Pi или аналогичного устройства**.

Предполагаемые технологии:

- Python;
- FastAPI или обычный HTTP-клиент;
- RPi.GPIO. или нет, если для khadas

Raspberry Pi(пока под вопросом) будет получать данные с сервера через REST API и показывать состояние планнера с помощью GPIO(опять же, под вопросом о khadas).

Например:

- зелёный светодиод - ближайших срочных событий нет;
- жёлтый - скоро занятие;
- красный - скоро важный дедлайн.

Также можно подключить кнопку для переключения информации или отметки задачи как выполненной.

## Сервер

Сервер нужен для связи Android-приложения, Raspberry Pi(khadas?) и внешних интеграций.

Предполагаемые технологии:

- <FastAPI / Node.js>;
- PostgreSQL;
- REST API;
- Docker.

Сервер будет отвечать за:

- хранение данных;
- авторизацию;
- загрузку расписания;
- домашние задания;
- заметки;
- уведомления;
- интеграции;
- обмен данными с Raspberry Pi?
