# Smart Student Planner

Мобильный ежедневник и учебный планнер для студентов с загрузкой расписания Пермского Политеха и отдельным Linux-устройством на базе Khadas (демонстрация на Linux VM).

## Идея

Приложение, в котором студент хранит в одном месте:

- расписание;
- задачи и события;
- домашние задания;
- дедлайны;
- заметки;
- напоминания.

**Главная особенность** — автоматическая загрузка расписания с сайта ПНИПУ. Расписание публикуется в Excel-файлах: сервер скачивает файл, разбирает его и добавляет занятия нужной группы в планнер.

---

## Компоненты

### Android-приложение
**Java + Android SDK.** Авторизация, расписание, планнер, задачи, ДЗ, заметки, push-уведомления. Общение с сервером по REST.

### Сервер
**FastAPI + Python.** Отвечает за бизнес-логику,
REST API, авторизацию, обработку расписания
и взаимодействие с внешними сервисами.

### База данных
**PostgreSQL.** Используется для хранения данных системы.

### Развёртывание
**Docker.** Используется для запуска компонентов системы.

### Linux / Khadas
**Python + REST-клиент + GPIO-слой.** Две реализации: `VirtualGPIO` (для VM) и `KhadasGPIO` (заготовка под реальное устройство). 

### Интеграции
- **Сайт ПНИПУ** — источник Excel-расписания;
- **VK API** — дополнительный канал уведомлений (не обязательный).

## User Story

Один основной пользователь — **студент**.

| ID | Название | Запрос | Критерии готовности |
|---|---|---|---|
| US-01 | Регистрация и вход | зарегистрироваться и войти, чтобы пользоваться личным планнером | можно создать аккаунт; вход по логину/почте и паролю; после входа видны только свои данные |
| US-02 | Выбор группы | указать свою группу, чтобы получать расписание ПНИПУ | пользователь указывает группу; система находит расписание; занятия появляются в приложении |
| US-03 | Просмотр расписания | видеть расписание, чтобы знать пары на сегодня и ближайшие дни | дата и время; предмет; преподаватель и аудитория (если есть); загрузка из Excel ПНИПУ |
| US-04 | Задачи и события | создавать свои задачи, чтобы хранить учебные и личные планы в одном месте | название, описание, дата и время, приоритет, напоминание; можно изменить и удалить |
| US-05 | Домашние задания | добавлять ДЗ по предметам, чтобы контролировать сроки | предмет, описание, дедлайн, приоритет, статус |
| US-06 | Отметка выполнения | отмечать задачи и ДЗ выполненными, чтобы видеть, что осталось | статус меняется на «выполнено» |
| US-07 | Заметки | добавлять заметки к занятиям и записям, чтобы сохранить информацию | заметку можно привязать к занятию, задаче или ДЗ |
| US-08 | Уведомления | получать уведомления о занятиях и дедлайнах, чтобы не забывать | работают в Android-приложении |
| US-09 | Уведомления через VK | получать дополнительные уведомления в VK | дополнительная интеграция, не обязательный способ |
| US-10 | Обновление расписания | обновлять расписание, чтобы получать актуальные данные | кнопка «Обновить расписание»; автопроверка — при наличии времени |
| US-11 | Linux / Khadas | смотреть ближайшие события через отдельное устройство, не открывая приложение | Linux-программа получает через REST ближайшее занятие, дедлайн и число активных задач; GPIO — для Khadas; в учебной версии — демонстрация на VM |

## Архитектура

Smart Student Planner использует клиент-серверную архитектуру.

Основные компоненты системы:

- Android-приложение;
- Backend на FastAPI и Python;
- база данных PostgreSQL;
- Linux-приложение на Python;
- сайт ПНИПУ как источник Excel-файлов;
- VK API для дополнительных уведомлений.

### Android-приложение

Предоставляет пользователю интерфейс для:
- авторизации;
- просмотра расписания;
- работы с задачами, домашними заданиями и заметками;
- получения уведомлений.

Взаимодействует с Backend через REST API.

### Backend

Реализуется на FastAPI и Python.

Отвечает за:
- бизнес-логику приложения;
- работу с пользователями и учебными данными;
- парсинг Excel-файлов с расписанием;
- взаимодействие с PostgreSQL;
- предоставление API для Android и Linux-приложений;
- отправку уведомлений через VK API.

### PostgreSQL

Используется для хранения пользователей, расписания,
задач, домашних заданий и заметок.

### Импорт расписания

Backend скачивает Excel-файл с сайта ПНИПУ,
обрабатывает его и сохраняет расписание в PostgreSQL.

### Linux-приложение

Разрабатывается на Python для запуска под Linux
на устройстве Khadas.

Приложение получает данные от Backend через REST API
и использует GPIO-слой для индикации.

Для демонстрации в Linux VM используется VirtualGPIO.
В дальнейшем предусмотрена возможность работы
с GPIO реального устройства Khadas.
